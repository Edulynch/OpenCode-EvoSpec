# Core Bootstrap Implementation Tasks

Tasks follow the implementation order in [plan.md](plan.md). Each task names its primary files, validation, dependencies, parallelism, and specification traceability. Use CPython 3.11+ and the standard library only. Tests use `unittest`, temporary repositories, deterministic fixtures, and no network, subprocesses, wall-clock assertions, or agent metadata.

## Explicitly Excluded From Core Bootstrap

The following are not tasks in this feature: all `/evospec.*` command implementations, including `/evospec.review`; locks and semantic lock enforcement; semantic search; agent plugins and integrations; ChangeBudget; MCP, network, or background services; servers; databases or vector databases; project autodiscovery and initialization; version-control operations; Spec-Kit source or templates; and any source modules, scripts, or artifacts outside the plan's standard-library Python modules and tests.
